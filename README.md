# Pesquisa LoL — Corpus Yiok

Repositório do corpus de vídeos do canal **Yiok** (League of Legends) para pesquisa sobre misoginia online.

## Estrutura

Cada vídeo tem uma pasta nomeada com seu `videoId`:

```
<videoId>/
  ├── audio.mp3          ← arquivo de áudio (a ser subido)
  └── descricao.md       ← metadados + descrição do vídeo
```

## Corpus

- **Total de vídeos:** 43 (22 longos + 21 shorts)
- **Período:** 21/08/2025 – 20/11/2025
- **Canal:** Yiok (`UC_GFcLxFl1WhIOpZTzf9FSg`)
- **Total de comentários:** 1.222
- **Total de views:** 418.042

## Método

Léxico MOL (Misoginia Online em Léxico) — léxico baseado em HurtLex PT + termos emergentes da comunidade de League of Legends.
